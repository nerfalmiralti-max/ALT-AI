# ALT QR audit matrix

- Product truth: baseline persistence, previous/baseline selection, stable fingerprints, issue deltas, release gate, blocker-aware verdict, page health, network/console normalization, performance thresholds, visual labels, ignored lifecycle, and version snapshots.
- Scanner truth: factual stages, cancellation, partial-page failure, bounded concurrency/time/bytes/events, browser cleanup, and deterministic grouping/scoring.
- Evidence truth: selectors, URLs, statuses, viewport/dimensions, axe nodes, console/network repetition, Lighthouse metrics, captures, and no invented fields.
- Interface truth: summary hierarchy, What Changed mode, screenshot comparison, activity ledger, print, keyboard, reduced motion, and 320/375/390/430/768/1024/1440 layouts.
- Security truth: initial and redirected DNS, IPv4/IPv6 special ranges, metadata endpoints, rebinding residual risk, protocols, downloads/popups/dialogs/floods, production/local split, API/assets, and secret handling.
- Validation truth: unit, scanner, two-scan mutation, E2E, production build, live home/report, real Lighthouse, real screenshots, and zero hidden failures.
